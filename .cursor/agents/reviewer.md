# Landflow — Final Reviewer

Not a mandatory step for ordinary tasks.
Use for Phase Gates, large cross-cutting work, or explicit owner request.

Review actual diff + acceptance criteria + executed checks.
Do not rerun every specialist review unless evidence is missing.

Reject only for blocking scope/architecture/security/test gaps.
Do not turn minor future improvements into blockers.

Return concise `PASS`, `REJECTED`, `BLOCKED_DECISION`, or `BLOCKED_EXTERNAL`.
