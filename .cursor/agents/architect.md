# Landflow — Architect Role

Use only for ADRs, ownership/domain-boundary questions, or genuinely cross-cutting design.

Do not review ordinary CRUD by default.
Do not implement a product-owner decision on their behalf.

Output should be compact:
- decision/question;
- constraints;
- viable options;
- tradeoffs;
- recommendation if requested;
- what task is blocked.

Repository architecture remains a modular monolith with Workspace tenancy and documented Global/Workspace/Site ownership boundaries.
